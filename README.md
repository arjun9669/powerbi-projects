## 📁 Folder Structure

Each project is organized into its own folder and contains:

- `.pbix` → Power BI dashboard file  
- `.csv` → Cleaned dataset used for analysis  
- `README.md` → Project-specific summary and insights  
- *(Optional)* `preview.png` → Visual snapshot of the dashboard

💡 *You can download any `.pbix` file and open it in Power BI Desktop to interact with the dashboards.*

## 🔍 Project Highlights

### 🏥 Healthcare Claims Fraud Detection
> Identifies patterns in inpatient, outpatient, and beneficiary data to flag suspicious providers and claims.

📌 **Features**:
- Merged 4 datasets into one model  
- Matrix visual and slicers for fraud analysis  
- Chronic condition breakdown

📁 Folder: [`Healthcare_Claims_Fraud_Dashboard/`](./Healthcare_Claims_Fraud_Dashboard)

---

### 🛒 Fake Product Review Detection
> Detects spam-like or fraudulent product reviews using behavioral patterns.

📌 **Features**:
- Verified vs unverified analysis  
- Review score distribution  
- Heatmaps of reviewer activity

📁 Folder: [`Fake_Review_Detection_Dashboard/`](./Fake_Review_Detection_Dashboard)

---

### 💳 Fraud Detection with ML Prediction
> Visualizes predictions made by a machine learning model to detect financial fraud.

📌 **Features**:
- Actual vs predicted fraud comparison  
- Demographic breakdown (race, gender, state)  
- Confidence score distribution

📁 Folder: [`Fraud_Detection_Dashboard/`](./Fraud_Detection_Dashboard)

---

### 🏛️ Union Budget 2025–2026 Dashboard
> A visual deep dive into India’s 2025–2026 Union Budget – showcasing allocations, expenditure categories, and departmental trends.

📌 **Features**:
- Budget Summary, Capital vs Revenue breakdown  
- Department-wise funding with YoY comparisons  
- Slicers, bookmarks, and custom navigation

📁 Folder: [`Budget_2025_2026_Dashboard/`](./Budget_2025_2026_Dashboard)
